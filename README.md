# Предобученные масочные модели для конечного BitSequence

Три реальные обученные модели, точная спецификация задачи, история обучения,
проверки калибровки и исходные артефакты. Это **пакет предобучения/reference**
для локального исследования TraFL, а не веса TraFL, LLaDA или JustGRPO.

Читать:

1. [Карточка предобучения: факты и определения](PRETRAIN_CARD_RU.md).
2. [Оценка результата и ограничения — отдельно от фактов](ASSESSMENT_RU.md).
3. [Загрузка, проверка и повторение обучения](REPRODUCE_RU.md).

**Известная ошибка истории100:**12500 реальных обновлений модели, но сохранённый
счётчик Adam16500. У101/102 оба числа12500. Это не скрытые дополнительные обновления;
подробности в карточке и [независимом аудите](evidence/PRETRAIN_OPTIMIZER_LINEAGE_REVIEW.md).
Исторические файлы не исправлены задним числом. Для нового обучения предлагается
фиксированная схема101/102, не ошибочный четырёхветочный диагностический скрипт100.

## Состав

| Путь | Что лежит |
|---|---|
| `artifacts/BS-soft-tail-1/ckpt_000500.pt` | Принятая модель100, Adam/RNG/metadata |
| `artifacts/BS-independent-base101/soft-low/ckpt_000500.pt` | Принятая модель101 |
| `artifacts/BS-independent-base102/soft-low/ckpt_000500.pt` | Принятая модель102 |
| `artifacts/` |13 конечных этапных и6 начальных checkpoint’ов, выбранные точные таблицы, журналы, манифесты, архивы исходников |
| `source/` | Байты всех членов source ZIP101 сохранены; дополнительно приложены явно обозначенные validation tests |
| `vendor/gfn/` |72 неизменённых Python-файла pinned torchgfn |
| `facts.json` | Полная матрица расстояний, oracle-величины, счётчики и SHA этапов |
| `inventory.json` | SHA256 и размер каждого распространяемого файла (кроме самого inventory) |
| `verify.py` | Проверка байтов; опционально загрузка и точная CPU-переоценка трёх моделей |
| `evidence/` | Аудит Adam, [независимый обзор пакета](evidence/PRETRAIN_PACKAGE_REVIEW.md), численные receipts/логи проверок |
| `source/research/bitseq_mps/tests/` | Добавленные при упаковке pretraining/evaluator/replay gates, происхождение сохранено |
| `licenses/` | Исходные уведомления/лицензии; пакет не перелицензирует чужой код |

Не включены остальные checkpoint’ы каждого промежуточного наблюдения, все RL-запуски,
локальные venv, токены/ключи и полный родительский репозиторий. `train.jsonl` и JSON
наблюдений сохранены; утверждение «все исторические бинарные снимки включены» неверно.
В оригинальных манифестах есть исторические абсолютные локальные пути.

Быстрая проверка без ML-зависимостей:

```bash
python3 verify.py
```

Проверка с загрузкой весов и переоценкой описана в REPRODUCE_RU.md. Никаких
многогигабайтных скачиваний модели или автоматического обучения при проверке нет.
